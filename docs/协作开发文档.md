# A3 协作开发文档

本文档用于把 `D:\A3` 上传到 Git 仓库后，给前端、后端和数据库协作者快速接手。

## 项目定位

A3 是面向大学生的个性化学习与智能辅导 Web 应用。当前产品只保留学生端，重点围绕本科课程学习、考试冲刺、科研项目训练和职业能力提升四类目标模式展开。

当前示例学生为大学本科生，课程内容围绕高等数学 A、线性代数、概率统计、数学建模等场景。已实现页面：

- 学习首页
- 学习画像
- 学习计划
- 资源推荐
- 智能辅导
- 学习报告

后端使用本地 Express API 连接 PostgreSQL。前端优先读取 API 数据，API 不可用时保留静态 fallback，方便 UI 开发不中断。

## 环境要求

建议版本：

- Git 2.4x 或更新
- Node.js 20 LTS 或更新
- npm 10 或更新
- PostgreSQL 16
- Windows PowerShell 或 Git Bash

当前开发机路径仅供排查，不要求队友完全一致：

| 工具 | 当前机器位置 |
| --- | --- |
| Git | `C:\Program Files\Git\cmd\git.exe` |
| Node.js / npm | `D:\New Folder` |
| PostgreSQL | `D:\PostgreSQL\16` |
| PostgreSQL 数据目录 | `D:\PostgreSQL\16\data` |
| psql | `D:\PostgreSQL\16\bin\psql.exe` |

## 环境变量

```powershell
cd D:\A3\frontend
Copy-Item .env.example .env
```

`.env` 示例：

```env
API_PORT=3001
PGHOST=127.0.0.1
PGPORT=5432
PGDATABASE=a3_learning
PGUSER=postgres
PGPASSWORD=你的本地数据库密码
```

不要提交 `.env`，不要把真实密码写进文档或代码。

## 安装与启动

```powershell
cd D:\A3\frontend
npm install
npm run api
```

另开一个终端：

```powershell
cd D:\A3\frontend
npm run dev
```

当前本机访问地址通常是：

```text
http://127.0.0.1:3001
```

## 数据库初始化

数据库目标名：`a3_learning`

优先使用项目脚本：

```powershell
$env:PGPASSWORD="你的本地 postgres 密码"
D:\A3\tools\init-a3-database.ps1
```

手动执行顺序：

```powershell
D:\PostgreSQL\16\bin\createdb.exe -U postgres a3_learning
D:\PostgreSQL\16\bin\psql.exe -U postgres -d a3_learning -f D:\A3\database\schema.sql
D:\PostgreSQL\16\bin\psql.exe -U postgres -d a3_learning -f D:\A3\database\seed.sql
```

## 数据归属

- 课程、学生资料、学习计划、任务、资源、推荐、画像、热力图、报告、AI 会话、目标模式都应落库。
- 页面 tab、临时输入、展开/收起、筛选条件可以是前端状态；需要恢复的 UI 状态写入 `student_ui_state`。
- 用户点击、开始学习、资源使用、报告导出等业务行为写入对应业务表或 `student_activity_events`。
- 推荐排序、报告指标、目标风险判断优先由后端根据数据库聚合或推理，前端只负责展示和触发操作。

## 目标模式

当前首页核心功能是目标模式切换。数据库表：

- `student_goal_modes`
- `student_goal_milestones`

接口：

- `GET /api/goal-modes`
- `POST /api/goal-modes/:modeKey/activate`

内置模式：

- `course_mastery`：课程掌握
- `exam_sprint`：考试冲刺
- `research_project`：科研项目
- `career_skill`：职业能力

## 已知注意事项

- PowerShell 有时会把 UTF-8 中文显示成乱码，文件本身通常仍是 UTF-8。遇到中文显示异常，优先用编辑器、浏览器截图或 Node UTF-8 读取确认。
- 数据库密码只放在本机 `.env` 或当前终端环境变量里。
- `frontend/node_modules`、`frontend/dist`、`artifacts`、安装包目录都不提交。
