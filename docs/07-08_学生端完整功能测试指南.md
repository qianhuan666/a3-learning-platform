# A3 学生端完整功能测试指南

更新时间：2026-07-07  
适用范围：学生端主线功能、后端 API、数据库写入闭环、Phase 1-6 开发成果  
测试分支：`Suo` 或已合并后的 `main`

## 1. 测试目标

本指南用于帮助队员完整验证 A3 学习平台当前学生端能力，重点确认：

- 学生端 6 个页面可正常访问和交互。
- 首页目标模式、学习计划、资源推荐、智能辅导、学习报告之间形成闭环。
- Phase 1-3 后端能力可用：诊断画像、智能计划、RAG 知识检索。
- Phase 5 多智能体分析可解释闭环可用。
- Phase 6 智能辅导体验优化可用：公式渲染、SSE 流式响应、停止生成、停止提示、KaTeX 按需加载。
- 关键用户行为会写入数据库或后端日志表。

```text

```

严重程度建议：

- 阻塞：无法登录、后端无法启动、核心页面白屏。
- 高：核心闭环失败，例如智能辅导不可用、计划无法写入。
- 中：局部功能异常，例如某个按钮无反馈、提示不准确。
- 低：样式、文案、轻微交互问题。

### 8.1 获取诊断题

```powershell
Invoke-RestMethod -Uri "http://127.0.0.1:3001/api/diagnosis/questions?courseId=course-linear-algebra&limit=5"
```

期望：

- 返回诊断题列表。

### 8.2 提交诊断答案

根据接口返回题目 ID 组装答案：

```powershell
$body = @{
  courseId = "course-linear-algebra"
  answers = @(
    @{ questionId = "替换为真实题目ID"; answer = "A" }
  )
} | ConvertTo-Json -Depth 5

Invoke-RestMethod `
  -Method Post `
  -Uri "http://127.0.0.1:3001/api/diagnosis/submit" `
  -ContentType "application/json" `
  -Body $body
```

期望：

- 返回诊断记录、得分或薄弱点。
- 数据写入诊断记录相关表。

### 13.4 停止生成

输入较长问题：

```text
请非常详细地讲解极限、导数、积分、矩阵特征值、概率分布与数学建模之间的联系，并举多个大学课程例子。
```

步骤：

1. 回答开始流式输出后点击“停止生成”。

期望：

- 流式输出立即停止。
- 忙碌状态结束。
- 页面显示：

```text
已停止生成。当前片段不会保存到历史记录，你可以继续提问。
```

- 可以继续输入新问题。
- 切换会话后提示消失。
- 被停止的部分回答不作为完整助手消息持久化。

## 21. 通过标准

## 22. 已知不作为失败项的问题

- 教师端暂缓，不作为本轮学生端测试失败项。
- 首次公式渲染时短暂显示原始公式 fallback，属于 KaTeX 按需加载预期行为。
- 如果本地未配置大模型 API Key，智能辅导可能走 fallback 或返回受限结果；此时应单独记录为“环境未配置”，不要直接判为功能失败。
- 浏览器控制台中与开发服务器热更新相关的普通提示不作为失败项。

## 23. 建议测试顺序

如果时间有限，优先按以下顺序：
