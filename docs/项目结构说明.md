## Data Direction

The current frontend still uses `localStorage` as a temporary mock store so the page can run without a backend service.

Data that should move to PostgreSQL:

- study plans
- task completion state
- learning resources and recommendations
- knowledge mastery heatmap values
- chat history, if product policy allows retention

UI-only state can stay in the frontend:

- active navigation item
- selected tab
- currently selected heatmap cell
- text currently being typed

## Encoding Note

PowerShell output on this machine may display UTF-8 Chinese source text as mojibake. Prefer browser screenshots, DOM checks, or UTF-8-aware scripts when verifying Chinese content.
