# 2026-06-11 更新说明

本次更新把 A3 学习平台的学生端演示内容从低龄数学场景升级为大学本科课程场景，并把主要按钮从“可点击”推进到“可记录、可恢复、可追踪”。

> 2026-06-19 后续更新：当前产品方向已改为学生端单端应用，教师端和家长端不再作为当前开发范围。以 `docs/协作开发文档.md`、`docs/数据库按钮绑定说明.md` 和数据库最新 migration 为准。

## 已完成

- 学生端六个页面内容切换为大学课程语境。
- 首页任务、学习计划、资源推荐、智能辅导、学习报告等按钮开始写入数据库或事件表。
- 新增 `student_ui_state`、`student_learning_sessions`、`student_resource_usage`、`report_exports` 等表。
- 智能辅导会话使用 `chat_sessions`、`chat_messages`、`chat_guidance_steps` 存储，不只保存在浏览器内。
- 新增 `docs/数据库按钮绑定说明.md` 说明按钮、API 和数据库表的绑定关系。

## 后续原则

1. 新增按钮前先判断：临时前端状态、可恢复 UI 状态、还是业务记录。
2. 可恢复 UI 状态写入 `student_ui_state`。
3. 业务行为写入对应业务表，轻量审计写入 `student_activity_events`。
4. 新增数据库字段或表时，同步更新 `database/schema.sql`、`database/migrations/*.sql` 和必要 seed 数据。
5. 前端允许保留 fallback，但正式页面数据应优先来自 API。
6. 视觉改动后必须运行 `npm run build`，并按项目 QA 规则做响应式截图和卡片溢出检查。
